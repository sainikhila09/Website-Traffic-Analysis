# 🌐 Website Traffic Analysis

## 📌 Project Overview

This project was completed as part of the **Alfido Tech Data Analytics Internship** through the **InternSpark** platform.

In this project, I analyzed website traffic data using Python to understand user activity, identify traffic patterns, and explore how website events were distributed across different countries, cities, artists, albums, and links. The analysis helped generate meaningful insights and practical business recommendations based on the available data.

---

## 🎯 Objectives

- Clean and preprocess the website traffic dataset.
- Perform Exploratory Data Analysis (EDA).
- Analyze website traffic patterns.
- Calculate key performance indicators (KPIs).
- Generate meaningful business insights and recommendations.

---

## 📂 Dataset

**Source:** Kaggle

**Dataset Link:**  
https://www.kaggle.com/datasets/bhanupratapbiswas/website-traffic-analysis


**Note:** The original dataset is approximately **30 MB**, which exceeds GitHub's web upload limit (25 MB). Therefore, it is not included in this repository. The processed dataset used for the analysis is available in this repository.

## 🔍 Key Findings

- Website traffic was spread across multiple countries and cities.
- A small number of artists, albums, and links received significantly higher user activity.
- Daily website traffic showed noticeable variations over time.
- KPI analysis provided a clear summary of total events, unique links, countries, and cities.
- The visualizations helped identify popular content and overall traffic patterns.

---

## 💡 Recommendations

- Promote high-performing links to increase user engagement.
- Recommend popular artists and albums based on user activity.
- Focus marketing efforts on countries and cities with higher website traffic.
- Monitor website traffic regularly to identify changes in user behavior.
- Use traffic insights to improve future content and promotional strategies.
